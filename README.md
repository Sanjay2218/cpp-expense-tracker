💰 C++ Expense Tracker
📌 Project Description
The C++ Expense Tracker is a beginner-friendly, menu-driven command-line application that helps users record and manage their daily expenses.
✨ Features

Add expenses with a name, category, and amount.
Display all recorded expenses.
Calculate the total expenses for a specific category.
Calculate the overall expense total.
Validate user input and handle invalid menu choices.
Display expenses in a readable table format.

🛠️ Technologies Used

C++
C++ Standard Template Library (STL)
Structures and vectors
Functions and control statements
Input validation

📋 Requirements

Windows, Linux, or another supported operating system.
A C++ compiler supporting C++17, such as GCC.
Visual Studio Code or another code editor.

🚀 How to Compile
Open the terminal in the project directory and run:
g++ -std=c++17 -Wall -Wextra expense_tracker.cpp -o expense_tracker.exe

▶️ How to Run
Windows (PowerShell):
.\expense_tracker.exe

Linux:
./expense_tracker

📖 How to Use

Run the program.
Select an option from the menu.
Add an expense by entering its name, category, and amount.
View all expenses using the List Expenses option.
Calculate category-wise spending using Category Total.
View total spending using Overall Total.
Select Exit to close the application.

🛡️ Input Validation
The application checks menu input, rejects empty expense names and categories, and rejects non-numeric or non-positive expense amounts.
💾 Data Storage
Expenses are stored in memory while the application is running. They are cleared when the program exits.
